## DRay 2.1.2

Release date: 2026-05-19
Build: 48

### Highlights
- Smart Care flow polish:
  - single contextual primary action: `Run Smart Scan` before results, `Clean Recommended` after scan results
  - scan and cleanup progress banners with elapsed time, per-analyzer/item status, and final summaries
  - safer empty state that explains scan-first / clean-later behavior instead of showing a misleading disabled cleanup action
- Adaptive layout correction:
  - `Adaptive` density now keeps comfortable layouts for normal windows and switches to compact only on genuinely small windows
  - Overview metric and insight cards now use deterministic `4 -> 2 -> 1` and `3 -> 2 -> 1` fallbacks to avoid squeezed cards and empty columns
  - Smart Care category cards have wider minimums and text wraps instead of truncating key explanations
- Search and cleanup workflow hardening:
  - Fast search avoids slow root fallback when Spotlight cannot serve `/`
  - bulk actions operate on the selected set predictably, including tree/subtree selection flows
  - Search display modes now differ more clearly, including a fuller tree workflow
- Uninstaller and Remaining clarity:
  - LaunchDaemons and privileged helper failures remain classified instead of collapsing into generic `Other`
  - Remaining cleanup now gives clearer next-step guidance for daemon/helper cases
  - Clean Uninstall reports unresolved leftovers transparently and routes them into Remaining for follow-up
- UI consistency pass:
  - module headers now share one visible glass header style across major sections
  - Overview, Performance, Settings, Smart Care and related empty states received spacing and compact-window polish
- Network workspace documentation:
  - added a progress tracker for the Network workspace modernization and current observability/tooling scope

### Changed
- Added focused tests for adaptive density thresholds.
- Updated release docs and README examples for the `2.1.2 (48)` channel.
- Bundled refreshed DRay icon assets and install-script icon handling carried forward from the stabilization branch.
