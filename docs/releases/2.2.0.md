## DRay 2.2.0

Release date: 2026-05-27
Build: 1

### Highlights
- Calm Liquid Glass UI refactor:
  - introduced a quieter shared visual foundation with calmer surfaces, semantic tones, subdued badges and button hierarchy
  - refined Overview, Smart Care, Search, Uninstaller/Remaining, Performance, Network, Settings and the menu-bar helper without removing controls
  - tightened dense text-first layouts where graphs were adding noise instead of useful information
- Network and Performance polish:
  - integrated the Live Map into the calmer visual system with muted map styling and readable connection paths
  - removed awkward nested scroll zones in diagnostic cards
  - made Battery & Energy, Startup and Network Overview more compact and metric-focused
- Cleanup safety:
  - Smart Care now blocks generic macOS preference/state cleanup by default
  - added explicit exclusions for Dock, menu bar, wallpaper, keyboard, trackpad, Stage Manager and related macOS state domains
- Energy Mode controls:
  - added Battery Power and Power Adapter energy mode controls in Battery & Energy
  - uses direct `pmset` first and retries root-required mode changes through a narrow administrator-authorized fallback
- Reliability:
  - kept Force Remove, App Store app deletion, Search filters/regex validation, Network tools, Full Disk Access diagnostics, Remaining cleanup and high-risk settings intact

### Changed
- Updated release docs and README examples for the `2.2.0 (1)` channel.
- Updated Network geolocation User-Agent to `DRay/2.2.0`.
- Added tests for protected macOS state cleanup exclusions and energy mode authorization fallback.
