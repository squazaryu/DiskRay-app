## DRay 2.2.1

Release date: 2026-07-30
Build: 1

### Highlights
- Network privacy is now explicit:
  - public-IP lookup and remote endpoint geolocation are separate opt-in capabilities
  - neither capability makes external IP-service requests while disabled
  - cached public/endpoint geolocation can be cleared from the Network Privacy menu
- Deep Sweep now reports ownership confidence and supporting evidence:
  - installed nested app helpers, extensions, XPC services, bundles, and plugins are excluded from orphan matching
  - ambiguous identifiers and shared/group containers remain visible for review but are excluded from automatic cleanup
  - only high-confidence candidates participate in verified batch cleanup
- Remaining UX now shows confidence/evidence and provides direct Reveal and Copy Path actions for manual review.
- Network and Remaining presentation was split into stateless feature-local components without changing feature state ownership.

### Reliability Included
- Required full-Xcode CI for pull requests and `main`.
- Streamed and bounded system-command output with timeout/cancellation cleanup.
- Atomic, root-scoped SQLite file-index snapshots with rollback and corruption recovery.
- Typed Remaining failure categories and remediation that no longer depend on localized UI text.

### Functionality Preserved
- Force Remove and administrator fallback.
- App Store-managed application deletion.
- Search filters and regex validation.
- Network Overview, Live Map, Tools, Port Scanner, Wake-on-LAN, and Speed Test.
- Full Disk Access diagnostics.
- Remaining cleanup and high-risk settings.

### Validation
- Full-Xcode debug build.
- Full-Xcode release build.
- Full Swift test suite.
- UI smoke checks and PII scan.
- Installed bundle identity/helper/signature verification.

### Distribution Note
- The local release environment has no Developer ID identity or notary profile. Published artifacts are ad-hoc signed and not notarized; macOS may require the standard first-open confirmation.
