## DRay 2.2.2

Release date: 2026-07-30
Build: 1

### Fixed
- The menu bar helper no longer rewrites `Contents/Resources/DRay.icns` after launch.
- The installed app keeps a valid sealed resource envelope after the helper starts.
- Release packaging now starts the embedded helper and repeats strict signature verification before creating artifacts.

### Icon Behavior
- The installer chooses the light or dark default icon before signing.
- While DRay is running, its Dock icon continues to follow the selected/system appearance through AppKit.
- Runtime code no longer modifies the signed app bundle.

### Functionality Preserved
- Force Remove and administrator fallback.
- App Store-managed application deletion.
- Search filters and regex validation.
- Network Overview, Live Map, Tools, Port Scanner, Wake-on-LAN, and Speed Test.
- Full Disk Access diagnostics.
- Remaining cleanup and high-risk settings.

### Validation
- Full-Xcode debug and release builds.
- Full Swift test suite.
- UI smoke checks and PII scan.
- Strict signature verification before and after helper startup.
- Installed app/helper launch verification.

### Distribution Note
- The local release environment has no Developer ID identity or notary profile. Published artifacts are ad-hoc signed and not notarized; macOS may require the standard first-open confirmation.
