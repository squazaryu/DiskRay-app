## DRay 2.1.3

Release date: 2026-05-21
Build: 1

### Highlights
- Uninstaller transparency and predictability:
  - preserved standard Trash, Finder recycle, admin Trash and high-risk Force Remove fallback chain
  - reports the actual removal method for app bundles, including admin and force-admin paths
  - verifies post-removal state and keeps unresolved app bundles/remnants visible for Remaining cleanup
  - keeps LaunchDaemon and privileged helper failures actionable instead of collapsing them into generic failures
- Shared safety and command execution foundations:
  - added a shared `PathSafetyPolicy` for protected, admin-sensitive, user-data, cache, app-bundle and remnant paths
  - moved key diagnostic/search commands behind a bounded `SystemCommandRunner` with timeout and cancellation handling
  - migrated Network `nettop`, latency `ping`, port scan `nc`, and Search `mdfind` paths to the shared runner
- Search correctness:
  - invalid regular expressions now return a validation error instead of silently falling back to substring results
- Settings and permissions clarity:
  - Full Disk Access now includes diagnostic probes with explicit readable/denied/missing state and likely granted/missing/partial/unknown status
- Network workspace persistence:
  - Resolve locations, data representation, and last port scanner host/start/end values persist across app restarts
- Menu bar helper reliability:
  - fixed helper startup crash caused by reading app appearance before `NSApplication` was initialized
  - kept dark/light app icon sync behavior for the closed-app/menu-bar lifecycle
- Smart Care and cleanup stability:
  - stable cleanup item/category IDs reduce selection and diffing resets after rescans

### Changed
- Updated release docs and README examples for the `2.1.3 (1)` channel.
- Updated Network geolocation User-Agent to `DRay/2.1.3`.
- Added focused tests for path safety, command-backed network parsers/services, invalid regex handling, uninstaller fallback/remnant verification, Full Disk Access diagnostics, and stable cleanup IDs.
